# Private Coursework Code

ECE 385 and ECE 391 produced substantial technical work, but the source code is
not included in this public portfolio.

Reason:

- Publishing reusable course solutions can create academic-integrity problems
  for future students.
- The resume can describe the work and the interview can cover architecture,
  tradeoffs, and debugging, but public source code is intentionally omitted.

This repo therefore focuses on non-coursework projects and reconstructed code
for lost personal/internship work.
